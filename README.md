# Maligayang Kaarawan, Schanel 💖

Página de cumpleaños en filipino para Schanel: caja de regalo de entrada, música de caja musical, pastel con velas para soplar, fotos enmarcadas como tesoros, corazones flotantes con mensajes secretos y una carta.

## Cómo verla

Abre `index.html` en el navegador, o publícala con **GitHub Pages** (Settings → Pages → elige la rama y la carpeta `/root`).

> Ojo: si el repositorio es público, las fotos también lo serán.

## Estructura

| Archivo | Qué hace |
|---|---|
| `index.html` | Estructura y texto de la carta |
| `styles.css` | Diseño y animaciones |
| `script.js` | Interacciones; arriba están las fotos y los mensajes (con traducción al español en comentarios) |
| `music.js` | Música sintetizada (Happy Birthday + canción de cuna) |
| `fotos/` | Las 5 fotos, ya rotadas y optimizadas |

## Poner otra canción

Sube un archivo llamado `cancion.mp3` junto a `index.html`. Si existe, se reproduce en bucle; si no, suena la caja musical.
